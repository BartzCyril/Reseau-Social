# Réseau social — maquette responsive

> Intégration HTML / CSS responsive de la page d'un réseau social à partir d'une maquette Figma.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

**👉 Voir le site : [bartzcyril.github.io/Reseau-Social](https://bartzcyril.github.io/Reseau-Social/)**

## Sujet

Exercice d'intégration : reproduire la maquette Figma d'un réseau social et la rendre lisible sur toutes les tailles d'écran, en HTML et CSS uniquement.

## Compétences acquises

- **Lecture d'une maquette Figma** : dimensions, espacements, couleurs, typographies
- **HTML sémantique** et structure de page
- **Responsive design** : mise en page qui se réorganise selon la largeur de l'écran grâce aux media queries
- Réflexion sur l'expérience utilisateur selon le support (mobile, tablette, desktop)

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
